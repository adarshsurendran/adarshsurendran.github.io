KMH GROUP OF HOSPITALS WEBSITE
==============================

PROJECT FILES
-------------

1. index.html
   Contains the complete website structure section by section.

2. styles.css
   Contains all colours, layouts, responsive design and visual styling.

3. script.js
   Contains mobile menu functionality, appointment date control and
   WhatsApp appointment booking functionality.

4. clinic-building.png
   Clinic image used in the hero banner.


HOW TO OPEN
-----------

Keep all four files inside the same folder.

Double-click index.html to open the website in a browser.


HOW TO EDIT
-----------

Clinic name, doctor names and services:
Edit index.html

Colours, font sizes, spacing and mobile layout:
Edit styles.css

WhatsApp number and appointment form functions:
Edit script.js
